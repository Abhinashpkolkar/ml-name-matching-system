# ML-Based Name Matching System

## Problem

Matching duplicate or similar names across datasets is challenging due to spelling variations, abbreviations, formatting inconsistencies, and typographical errors.

---

## Solution

Built an intelligent name matching system using NLP and machine learning techniques to identify duplicate entities across noisy datasets.

---

## System Pipeline

Name Pair Generation → Feature Engineering → Similarity Computation → ML Classification → Match Prediction

---

## Tech Stack

* Python
* Scikit-learn
* XGBoost
* Sentence Transformers
* Pandas
* NumPy

---

## Features Used

* TF-IDF similarity
* SBERT embeddings
* Jaro-Winkler similarity
* Phonetic similarity
* Token-based matching metrics

---

## Models Used

* Logistic Regression
* Random Forest
* XGBoost

---

## Key Features

* Hybrid similarity feature engineering
* Semantic and phonetic matching
* Robust duplicate detection across noisy datasets
* Scalable ML-based record linkage pipeline

---

## Future Improvements

* Real-time matching API
* FAISS-based approximate nearest neighbor retrieval
* Deep learning-based entity resolution
